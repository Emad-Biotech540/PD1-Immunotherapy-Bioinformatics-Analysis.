# PD-1 Immunotherapy Bioinformatics Analysis

## Overview
This repository contains a bioinformatics data analysis pipeline implemented in Python. The project explores gene expression profiles and identifies key biological pathways associated with tumor response to **PD-1 checkpoint inhibitor immunotherapy** in cancer treatment.

## Key Features
* **Data Processing & Filtering:** Utilizes Python (`pandas`) to filter and analyze differentially expressed genes (DEGs) relevant to immunotherapy response.
* **Pathway Enrichment Analysis:** Implements `gseapy` to perform pathway enrichment against human databases (such as KEGG) to uncover active immunological mechanisms.
* **Data Visualization:** Generates professional, publication-ready plots (dot plots and statistical summaries) using `matplotlib` and `seaborn` to visualize T-cell receptor signaling and PD-L1 pathways.

## Technologies & Libraries Used
* **Language:** Python
* **Data Manipulation:** Pandas, NumPy
* **Bioinformatics:** GSEapy (Gene Set Enrichment Analysis in Python)
* **Visualization:** Matplotlib, Seaborn
* **Environment:** Google Colab / Jupyter Notebook

## How to Run
You can view and execute the complete interactive analysis directly in your browser via Google Colab by clicking the notebook file:
